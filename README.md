# 🏃 RunRush - Endless Runner Game

RunRush is a fun and interactive **Endless Runner Game** built using **HTML, CSS, and JavaScript**.

The player controls a runner moving through three lanes while avoiding obstacles and collecting coins. The game becomes faster as the player continues running.

## 🎮 Features

* 🏃 Endless runner gameplay
* 🛣️ Three-lane road
* 🚧 Random obstacles
* 🪙 Collectible coins
* ⬅️ Move left
* ➡️ Move right
* ⬆️ Jump
* 📈 Increasing game speed
* 🏆 Score system
* 💰 Coin counter
* 💥 Collision detection
* 🎮 Keyboard controls
* 📱 Mobile touch buttons
* 🔄 Restart option
* 📱 Responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* CSS Animations
* Browser APIs

## 🚀 How to Run

No installation is required.

### Step 1

Download or clone the repository.

### Step 2

Open the project folder in VS Code.

### Step 3

Make sure these files are present:

```text
index.html
style.css
script.js
```

### Step 4

Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code.

## 🎮 How to Play

### Keyboard

```text
←  Move Left
→  Move Right
↑  Jump
Space  Jump
```

### Mobile

Use the on-screen:

```text
⬅️   ⬆️   ➡️
```

buttons to control the player.

## 🏆 Game Rules

* Avoid 🚧 obstacles.
* Collect 🪙 coins.
* Every collected coin increases the score.
* The game speed gradually increases.
* Hitting an obstacle while not jumping ends the game.
* Try to achieve the highest score possible.

## 📊 Scoring

The game rewards:

```text
Running → Score increases
Coin 🪙 → +25 points
```
